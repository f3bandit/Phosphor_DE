Phosphor_DE {VERSION}, a kernel for the **EZ-Flash Omega Definitive Edition** (Rev B tested, Rev A untested). Tested and working on real hardware and on the Analogue Pocket.

**Not for** the original Omega, the newer blue "Omega DE B" (`ezbluekernel.bin`), or any other cart.

### Download
- **Phosphor_DE_{VERSION}.zip**: everything you need. Copy the `SD card` folder's contents to your microSD root, hold **R** at power-on.
- `ezkernelnew.bin` on its own ({SIZE} bytes, md5 `{MD5}`).

### What's in it
- New Phosphor UI: GBA only, scrolling long names, Tamzen font on dark grey, SD / NOR / Recent / Settings tabs
- New cheat engine and cheat pack: **1,700 games, 28,642 ready-to-play cheats** (GameHacking.org + libretro), nothing to type in, Anti DMA automatic
- NOR Check (dead-cell test) and read-only boot chip dump
- Optional loader recolor: `loader/de-recovery-phosphor.img` (the bright blue install screen goes grey; flash it from safe mode, see the README)

Full guide, SD card layout, tools and disclaimer: see the [README](https://github.com/f3bandit/Phosphor_DE#readme).
